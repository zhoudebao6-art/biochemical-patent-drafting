# 表格、图片分析和总结通用规范

按2026-10-20用户截图反馈执行，适用于新案全部表格和相应正文。此处图片分析位置覆盖原始注意事项“结果分析后面”的旧要求；原始txt只读留证，不再作为位置指令执行。不把截图中的材料、指标或数据写成通用模板事实。

表格用独立格式：单元格文字及表头水平居中、垂直居中，首行/悬挂/左右缩进为0，段前段后为0，自然行距与行高，不继承正文的首行两字符、两端/分散对齐或固定24pt行距。表头文字连续，不用空格撑宽；单位与指标居中对应，可合理分行，保留单位括号、上下标和有效数字。保留原边框、行列、合并层级、样品编号、误差、缺值和注记，不凭空改成三线表或补造指标。每张独立表都有自己的编号表题，居中、不加粗且随下表，不拿表题充作列头。

每表按本案来源逐列核对“样品/条件—指标—单位—数值”对应。不能把前表表头复制到后表，不能把数据首行误当表头。默认单行列头；源确有多层列头时显式指定table_header_rows，连续前N行作为整体重复表头。跨页重复的是本表真正表头，单行不拆页，表间保留结构分隔。最终实际看全部相关页，核表头完整、换行自然、各列对应和续页表头；只看XML不能证明没有截断或错列。不能用缩小文字至不可读来塞表。

结果分析顺序固定：结果分析标题→逐图分析（图号顺序，各图全部解释段连续）→原综合结果分析→保留的总结正文。不要重复粘贴已存在的图分析，不删除原结果或改写成新的实验。附图说明仍放图名，末区图下仍只图N。若来源缺少可绑定的结果分析位置或图解释，应定位缺口，不编造分析。plan用figure_analysis标记整组多段解释；工具同时识别源图解释定位并记录顺序调整。

删除独立标题或段首标签“技术总结”“技术总结：”，保留后续全部技术正文及权衡限制，不删除段落结论。总结正文已有明确主语则保留；缺少主语时补“本发明”，如“技术总结：以……”改为“本发明以……”，“采用……”改为“本发明采用……”。不得重复写“本发明本发明”，不得根据词首机械断定所有语法；复杂句由写稿及独立review核主语。plan可用technical_summary标记无标签总结段，summary_subject=present/missing记录实际语义判断，不用present豁免实际缺主语问题。正文中正常引用“技术总结”这个词时不全局删词。

生成器保留原始来源及技术对象，只改显示布局、段序、标签及必要主语。inspect_docx同次提取当前SHA的biochemical_table_evidence及biochemical_analysis_evidence，最终pass/交付拒绝缺失、过期、不完整或机械错误。段落角色用不显示的Word样式记录，以定位多段图分析，不在稿件中加内部标签。source_support复核原表和顺序映射，figures核全部图解释位置与完整性，rendered_pages看当前全部页；主语语义和列头含义仍须独立复核，与原六项并入同轮，不新增审查池或重复全检。

## 2026-10-21标题、字重与逐表表题

只将正式名称及五主栏目作为加粗标题，不额外生成有益效果、技术方案、制备方法等标题。有益效果正文前只保留普通正文句“与现有技术相比，本发明的有益效果在于：”，删去单独有益效果标题及本发明带来的技术效果如下等重复引导，编号效果和技术限定完整保留。说明书总体方案依源连贯叙述，不机械套用权1的分步换段规则。

制备工艺、配方、测试等源内标签保持正文常规字重；各实施例与对比例的性能测试结果等表题也不加粗。Word普通段显式b=0、bCs=0并去标题样式及大纲级别，避免间接继承加粗。截图红框和绿色背景是批注/界面提示，不复制到专利中。

每张独立表上方都有“表N＋说明”，不能只有表1有而表2缺失；同一跨页表继续重复自己的列头，不给每个续页新编一张表。性能测试表组沿人工终稿用“测试结果如表1至表N所示。”衔接，逐表居中写“表1各实施例与对比例的性能测试结果1”“表2各实施例与对比例的性能测试结果2”等，文字无空格、不加粗。源已有各表具体说明则保持其含义，勿生搬性能标题到配方或设备参数表；无可绑定表题时核源补计划，不造指标。保留原表数据、单位、上下标、原图及段序规则。

表题紧随本表，表题与列头及至少一行数据同页；表头行内部段落keepNext连接首行数据，数据行自然跨页，不将整表或整章全部keepNext。表题与表之间不能残留打断跟随关系的纯空段；不能因清理空段删除图像/数学/域对象。最终实际看页尾，避免只剩表题或只有列头。

当前同SHA完整biochemical_presentation_evidence检查额外标题/引导、普通段实际加粗、逐表表题及顺序，与table/analysis/spacing证据一起用于pass和交付。主栏目层级、源表题含义及真实分页仍并入六项独立复查，不新增池或独立审查轮次。
