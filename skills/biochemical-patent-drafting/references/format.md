# 五组人工稿的格式

原DOC只读保留SHA，转换DOCX用于格式取证，不能声称转换后字节等同原DOC。五组均五分区且页面几何一致，正文角色行距并非全部相同；2026-10-21复核见[实施例来源](example-format-user-requirement.txt)。assets/patent-template.docx只留样式、五分节、页眉页脚，无原技术正文、数据表和图片。参数见assets/format-profile.json，公开样本数量与结构统计见sample-evidence.json；原始题名及原件哈希证据仅留维护工作区。

|角色|默认值|
|---|---|
|页面|A4 11906×16838twip；上/左1418，右/下1134，页眉/页脚567|
|分区|说明书摘要→摘要附图→权利要求书→说明书→说明书附图，各另起页；不固定页数|
|文字|宋体/Times New Roman，12pt，黑字净稿；不沿用软通14pt|
|摘要/权项正文|首行两字符、段前5pt、段后0、固定24pt行距；高公式/图片局部调整，不裁切|
|说明书普通正文与实施例首段|首行两字符、段前5pt、段后0、1.3倍自然行距（auto312），12pt宋体/Times New Roman、常规字重；编号与完整引导同段，配方和工艺按源另段。不把摘要/权项固定行距通套说明书；高对象仍核不裁切|
|正式名称|12pt加粗居中，与核定名称及正式文件名一致|
|主栏目标题|仅技术领域、背景技术、发明内容、附图说明、具体实施方式，12pt加粗，约1.3倍行距，跟随下一段|
|普通标签及表题|制备工艺、配方、结果分析等为正文常规字重；每表上方有连续编号和有据表题，居中、不加粗、不缩进，与本表表头及至少一行数据同页|
|页眉|五分区名称，说明书页眉为说明书，不插入字面空格；保持模板横线和定位|
|页脚|样本横线与真实PAGE域，各分区从1计；不复制原稿缓存页码|
|图|原纵横比，主图在摘要图，全部图集中末区；图下仅图N并同页|
|表|全表及表头水平/垂直居中、无缩进、段前后0、自然行高，表头不用空格撑宽；保留源列名/单位/上下标/行列/合并/注记，跨页重复本表真正表头|

保留化学名称必要括号和符号；所有成稿文字无空格，页眉显示说明书，缩进及间距用Word属性实现，详见[无空格规范](no-spaces.md)。正文自然跨页，不整篇keepNext，不为填页改实验内容；分节附末段。图名进附图说明，解释紧接结果分析标题、位于原综合分析之前，原图和图下号进文末。所有最终页逐页看图，核长化学名、上下标、表格跨页、页眉页脚和图文位置；XML与工具成功不等于视觉通过。明确用户格式覆盖此经验模板，不冒称法律标准。

独立表格之间的源空段是布局对象，不能在只复制非空文本时漏掉；Word/WPS可能把相邻表格合并并沿用错误重复表头。生成器在相邻独立表缺分隔时插入1pt纯布局段，原表内容不改。最终仍核每张表的表头、列意义及跨页续行。

表格使用独立段落格式及真实表头，表题居中随下表，具体规则和视觉验收见[tables-analysis-summary](tables-analysis-summary.md)。删除技术总结标签但不删技术段，无主语补本发明。

不增设有益效果等额外标题；有益效果正文前仅保留常规字重引导句“与现有技术相比，本发明的有益效果在于：”。普通标签及表题显式取消b/bCs并清除继承的标题/大纲格式，不能只删直接加粗后仍继承样式。表题规范和独立验收见[tables-analysis-summary](tables-analysis-summary.md)。

终稿页面必须无底色：页面颜色设为无颜色，删除w:background（包括白色填充），清除正文、表格/单元格、页眉页脚的底纹及文字高亮，并清除样式、条件表格样式、编号层级中的继承底纹。保留黑色文字、表格边框、化学上下标、原图及科学内容；不以白色覆盖色冒充无填充。原始文件只读，清理只作用于生成副本。最终逐页看图确认无装饰铺底；WPS/Word护眼显示是应用视图设置，不能当作文件底色或修改用户全局显示偏好。

上下标采用普通字符加Word原生字符属性，不使用Unicode特殊上下标字符作替代，覆盖正文、权项、表格/表头、页眉页脚及可编辑图中文字。原生数学公式仍保留OMML结构。负指数的负号和数字整体上标；原有正确上下标不变，普通数字不机械转化。详见[chemistry-data](chemistry-data.md)。

附图说明前面各条以中文分号“；”结尾，最后一条以中文句号“。”结尾；只有一条时用句号，不用英文标点。按实际列表末项判断，不按固定图号或缓存数量判断。生成器仅修改该列表条目的末尾标点，保留富文本、上下标、数学及内容；presentation证据拦截错误末尾。
