# 2026-10-21实施例格式与完整引导句

用户将只有“实施例1”后直接接S1的截图判为错误，将编号和完整引导句同段、随后另段写配方的截图判为正确，并要求技术项目优化书中的完整引导句不得漏字，提取此前正确人工终稿格式作通用修复。

完整引导句的通用结构示意为“实施例1：本实施例为【本案完整技术名称】的优选实施例。”。方括号内容仅为占位示意，不是原样本技术名称；实际案件须完整保留各自来源引导句，不复制学习样本的技术名称、配方或数值。

原五组人工终稿转换件的哈希证据仅留维护工作区；公开sample-evidence.json只提供匿名编号及结构统计，不含原件哈希。五稿均有编号与完整引导同段，随后配方另段、再制备工艺或使用方法。四稿该处line=312、lineRule=auto，一稿继承auto360，均非摘要/权项的固定24pt。当前通用说明书普通正文取多数一致1.3倍，原案差异保留为证据，不声称五稿参数完全相同。无空格、无底色及原生化学上下标按用户已有规则继续执行。
