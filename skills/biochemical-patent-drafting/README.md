# 生化专利撰写自动化v1.2.0

独立技能名：`biochemical-patent-drafting`。基于[上游v6.37](https://github.com/zhoudebao6-art/patent-drafting-automation/releases/tag/v6.37)，用于生物、化学、材料及环境项目书的Word专利撰写、独立复查和逐案交付。讨论规则、提供样本或询问用法只进入维护。

将完整目录放入`%USERPROFILE%\.codex\skills\biochemical-patent-drafting`；自定义CODEX_HOME时使用其skills目录。新电脑先按[运行环境](references/runtime.md)探测和配置真实依赖。技能包不含外部运行程序，本机路径和历史验证不能证明新电脑已就绪。

```text
请使用$biochemical-patent-drafting处理“D:\待撰写生化项目”中的技术项目优化说明书及对应附件，按最新生化规则撰写专利Word，逐案独立复查、修改和页面检查，通过一案立即交付到桌面同一批次文件夹。
```

规则库v12、29条活动规则保持不变。完整权项写法、实际继承链、原生上下标、无底色、无空格、逐表说明及附图说明前项分号末项句号等要求见[规则库](references/rules.json)和[阶段规范](references/worker-standard.md)。样稿只供学习格式，本案材料决定技术内容；不套用固定十项或具体样本参数，不公开上传原始样本。

v1.2.0精简：生成命令增加`--check`，一次完成草稿及两项机械检查；源证据不再重复整段XML，保持来源定位及对象信息；生化预检共用一次文档快照和已解析XML；新运行快照排除未使用的软通数学辅助模块。没有增加调度层，保留三池、冻结身份、独立复查、真实页面验收和即时交付。旧证据和原命令继续兼容，旧冻结批次不自动变更。

入口为SKILL.md；维护测试按改动选择`python scripts/test_groups.py --group biochemical`或`--group workflow`。测试不调用付费模型；维护回归不替代未来案件的语义和页面验收。原始样本及验证产物留在维护工作区，assets/patent-template.docx只包含生成器占位内容。

公开分享包保留匿名样本结构统计及已清洗的五分区模板；不含原始题名、原件哈希、技术项目书、人工终稿、实验数据或图片。runtime.json保持空配置，必须在新电脑探测并验证Python、文档渲染器、WPS或LibreOffice、Poppler和字体后填写；安装技能不等于环境就绪。未配置时预检会拒绝运行。

本次五案维护验证的源证据总量由2,378,076降至479,388字节；生化预检的文件读取由9次降至2次；生成与两项检查由三条命令合为`bio_author.py --check`一条；新运行快照由76个文件降至75个。五案50条权项、72个真实自然段及来源Word XML/媒体等价检查通过。主回归共245项（100+101+44）通过；独立验证重复执行的用例不另叠加到此数量。以上是维护检查结果，不代表未来案件的语义/页面验收或产能实测。
