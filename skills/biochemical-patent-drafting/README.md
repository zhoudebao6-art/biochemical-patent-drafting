# 生化专利撰写自动化v1.7.0

独立技能名：`biochemical-patent-drafting`。基于[上游v6.37](https://github.com/zhoudebao6-art/patent-drafting-automation/releases/tag/v6.37)，用于生物、化学、材料及环境项目书的Word专利撰写、独立复查和逐案交付。讨论规则、提供样本或询问用法只进入维护。

将完整目录放入`%USERPROFILE%\.codex\skills\biochemical-patent-drafting`；自定义CODEX_HOME时使用其skills目录。新电脑先按[运行环境](references/runtime.md)探测和配置真实依赖。技能包不含外部运行程序，本机路径和历史验证不能证明新电脑已就绪。

```text
请使用$biochemical-patent-drafting处理“D:\待撰写生化项目”中的技术项目优化说明书及对应附件，按最新生化规则撰写专利Word，逐案独立复查、修改和页面检查，通过一案立即把终稿放回对应案件小文件夹，文件名严格使用小文件夹完整名称加.docx，保留原项目书和附件。
```

规则库v18、29条活动规则；补强所有多独权案件的前文引用，保留原撰写和验收要求。完整权项写法、实际继承链、原生上下标、无底色、无空格、逐表说明及附图说明前项分号末项句号等要求见[规则库](references/rules.json)和[阶段规范](references/worker-standard.md)。样稿只供学习格式，本案材料决定技术内容；不套用固定十项或具体样本参数，不公开上传原始样本。

交付规则：新批次按原始项目书所在小文件夹保存终稿，例如“总目录/案件甲/案件甲.docx”。正式技术标题仍以本案材料核定，文件名独立取自小文件夹；不加“终稿”或日期后缀。建批及发布时检测同名冲突，保留已有文件并报告，不覆盖、不改名兜底。直接提供单案小文件夹时同样适用；一个文件夹含多案须先分清目录。说明见[批次流程](references/batch-workflow.md)。

v1.7.0精简：检查链精简：预检取消只用于计数的整表单元格文字矩阵，保留合并单元格结构验证；版式检查共用本次调用的文字视图，附图说明只定位一次；删除空间扫描中未使用的祖先列表及遗留导入。沿用现有模块，不新增调度层或跨稿缓存。规则v18、29条规则、完整多独权引用、自然换页、16/8/8总并发上限32、独立验收及原案小文件夹同名交付均保持。

当前并发：初稿16、复查8、修改8，总并发上限32，不跨池借位。64GB内存按此作为建议上限；主控仍显式填写本批实际可用workers，不足32时填更低值。64是在制案件缓冲上限，不是CLI并发数。新批次采用新配置，旧冻结批次继续使用原配置。

入口为SKILL.md；维护测试按改动选择`python scripts/test_groups.py --group biochemical`或`--group workflow`。测试不调用付费模型；维护回归不替代未来案件的语义和页面验收。原始样本及验证产物留在维护工作区，assets/patent-template.docx只包含生成器占位内容。

公开分享包保留匿名样本统计和已清洗模板，不含原始技术项目书、人工终稿或个人运行路径。runtime.json保持空配置，新电脑须按references/runtime.md探测依赖、配置环境并完成预检及小样实际渲染。
