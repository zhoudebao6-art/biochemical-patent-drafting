# 生化专利撰写自动化 v1.1.4

独立技能名：`biochemical-patent-drafting`。基于[上游v6.37](https://github.com/zhoudebao6-art/patent-drafting-automation/releases/tag/v6.37)提交`9e13d1e70146497b9c1f11a2f694ed2c586ded9c`的完整三池/CLI/冻结/独立复查/增量复用/即时交付架构，重新建立生化规则与人工Word模板。不修改原软通技能，不把样本当生产案件，不公开上传样本。

将本目录整体放到`%USERPROFILE%\.codex\skills\biochemical-patent-drafting`，自定义CODEX_HOME时用其skills目录。本公开分享包清除了本机运行路径、模板账户元数据和样本身份；程序及规则与v1.1.4一致。首次安装按references/runtime.md探测Python、文档渲染器、WPS/LibreOffice、Poppler及字体，并填入空白runtime.json，再做预检和小样渲染。包不包含外部程序。

新聊天中可直接说：

```text
请使用 $biochemical-patent-drafting 处理“D:\待撰写生化项目”中的技术项目优化说明书，按照生化规则和人工终稿格式撰写，逐案独立复查、修改，通过一案立即交付到桌面同一批次文件夹。
```

支持化学合成、生物处理、聚合物/材料与环境治理类项目。章节映射、权项客体/父链、化学上下标、实验/推演属性、原表及全部谱图按本案来源处理。保留必要化学括号，不套软通固定十项或模块替换规则。制作/更新技能和提供学习样本时不会自动启动案件。

SKILL.md为入口，references/rules.json为独立规则库；references/sample-evidence.json仅记匿名样本编号和格式取证，不含原始技术正文/数据/图片。assets/patent-template.docx为脱敏五分区模板，内部BIO_SLOT是生成器用的占位段，生成后全部移除。测试产物、失败证据和完整样本只留创建工作区，不装进技能。

维护验证：用已具备python-docx/lxml/Pillow的解释器执行`python scripts/test_groups.py --group biochemical`或`--group workflow`，新增技能入口再用skill-creator的quick_validate.py。测试不调用付费模型；源样本前向验证和实际渲染另记validation记录，不冒称生产整批已验收或产能达标。

当前版本v1.1.4，规则v12，共29条。保留既有无底色、无空格、原生上下标、逐表说明、图分析顺序及附图说明前项分号、末项句号规则；合入完整实施例引导同段与说明书1.3倍行距修复。只用于新建批次。

沿用的架构精简：三项显示清理共用一次原子事务；三项检查共用XML解析；阶段说明去重复，规则原文和例外仍完整保留；新快照不复制未启用的软通生成器，检查器移除未调用的旧软通预检。三池、独立复查、冻结证据及即时交付不变。维护验证不等同于生产终稿验收或产能实测。

既有权项修复：五稿50项重新提取核对，客体分组与从属条件组合分开判断；续段与实际生成正文纳入校验。双/三客体使用来源支持的通用结构，五稿本身均为单独权。详见references/claims-patterns.md。

既有标点修复：附图说明前项为中文分号，最后一条为中文句号，单条列表也用句号；生成和检查按同一列表位置规则执行。

既有引用序号修复：X按实际进一步限定所需承接的条件确定，源绑定依据必填并逐支核完整链；与“所述”全局首次引入另查。普通从属客体不一致不再误归类为新独立项。

本次完整写法修复：重新逐源提取五稿50项72自然段，生成端恢复独立方法引导/步骤分段并合并从属项内部碎段，检查源候选顺序及完整客体。保留S步骤内部分号，不把从权内部制备过程另立项；收紧其中过渡及单位编辑。规则仍29条，未新增流程层或必填分段元数据。
